# desk — 桌面整理助手

把用户 Windows 电脑的桌面整理成编号的类别文件夹，并让各个会话做出来的东西（笔记、报告、程序、作业）
直接送进对应的类别，不再散落在桌面上。所有移动都记日志，可以撤销。经 `tsx sh mac` 在用户电脑上执行。

## 类别（categories.txt）

```
01 学习笔记   02 研究报告   03 课程作业   04 个人材料   05 代码项目
06 工作材料   07 图片截图   08 软件安装包  09 杂物
```
类别里可以再分子目录，例如 `学习笔记/CFA`、`学习笔记/量化面试`。快捷方式（.lnk/.url）、`Claude 会话台.cmd`、隐藏文件留在桌面。

## 用法

```bash
desk ls [类别]                      # 看桌面现状（各类别里有什么、还有哪些散落的）
desk plan                           # 预演：散落的东西按规则各去哪（不动文件）
desk tidy                           # 真正整理；规则判断不了的留在原地并列出来
desk mv 名字... -c 类别[/子目录] [--as 新名]   # 手动归类；名字可以是 '09 杂物/简历.pdf' 这种相对桌面的路径
desk put 文件... [-c 类别[/子目录]] [-f]       # 把 mini 上的产物送进桌面某类别（代替 tsx push -d ~/Desktop）；-f 覆盖同名
desk big [--min 300] [-y]           # 类别里超过 N MB 的子文件夹 → 本体移到 D:\桌面大文件\类别\，原处留快捷方式
desk undo [日志名]                   # 撤销最近一次（或指定一次）tidy / mv / big
desk log                            # 历次操作
desk cats                           # 类别和规则
```

## 规则

- 通用规则 `rules.tsv`（进仓库），私人规则 `~/.config/desk/rules.local.tsv`（不进仓库，优先）。
- 每行 `类别[/子目录]<TAB>通配模式`，不分大小写；`d:` 只匹配文件夹，`f:` 只匹配文件；`@留在桌面` 表示不动。
  从上往下第一条命中为准。规则判断不了的东西不会乱放，由会话看名字/内容后用 `desk mv` 归类，
  经常出现的就加一条私人规则。

## 依赖和前提

- 用户的电脑在线（会话台窗口或命令窗口开着；连不上先 `pcwait`）。
- 日志在 `~/data/tools/desk/logs/`（~/data 不在时用 `~/.local/state/desk/logs/`）。

## 注意

- 文件在用户电脑上开着（WPS、PDF 阅读器）时移不动，会报“being used by another process”，关掉再 `desk tidy`。
- 移动代码项目后，`.venv` 里的 pip.exe 等启动器写死了旧路径，用 `python -m pip`，或重建虚拟环境；PyCharm 里重新打开新位置。
- 用户的桌面在 `D:\HuaweiMoveData\Users\<WinUser>\Desktop`（华为电脑管家搬到了 D 盘），本身就不占 C 盘；
  `desk big` 只是让桌面文件夹变轻、大文件集中放。
- 只移动、改名、建快捷方式，从不删除用户文件。
