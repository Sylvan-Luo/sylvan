# desk：桌面整理 + 产物归档

桌面上是编号的类别文件夹：01 学习笔记 / 02 研究报告 / 03 课程作业 / 04 个人材料 / 05 代码项目 /
06 工作材料 / 07 图片截图 / 08 软件安装包 / 09 杂物（可带子目录，如 学习笔记/CFA）。快捷方式留在桌面。

```bash
desk put 报告.pdf -c 研究报告              # ★ 给用户送产物都用这个（代替 tsx push mac x -d "~/Desktop"）
desk put 权益全本.pdf -c 学习笔记/CFA -f    # 带子目录；-f 覆盖旧版本
desk ls                                    # 看现状、有哪些散落
desk plan / desk tidy                      # 预演 / 按规则整理（判断不了的留原地）
desk mv 名字... -c 类别[/子目录] [--as 新名] # 手动归类（名字可写 '09 杂物/简历.pdf'）
desk big --min 300 -y                      # 大文件夹本体移到 D:\桌面大文件，原处留快捷方式
desk undo                                  # 撤销最近一次
```

- 放哪类：笔记/讲义/备考 → 学习笔记；研究、量化、因子报告 → 研究报告；作业、课堂展示 → 课程作业；
  证件/简历/成绩单 → 个人材料；程序、notebook → 代码项目。同一项目多份文件就建子目录。
- 规则判断不了的不会乱放：自己看名字决定后 `desk mv`，常见的加进 `~/.config/desk/rules.local.tsv`（私人规则）。
- 文件开着移不动，告诉用户关掉再 `desk tidy`。从不删除文件。告诉用户文件放到了哪里（desk 会打印路径）。
- 细节见 ~/tools/desk/README.md。
