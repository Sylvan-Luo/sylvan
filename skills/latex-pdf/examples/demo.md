## 数字图像表示

### 位图与矢量图

::: def
### 位图（像素图像、点阵图）
由称作[像素]{.hl}（pixel）的单个点组成的图像，每个像素是一个小方格、只有一种颜色。[L2 p.8]{.src}
:::

::: {.def title="分辨率"}
单位长度内含有的像素数（常用单位"像素/英寸"，ppi）。分辨率越高图像越清晰，但文件越大。
:::

::: key
$$L = \frac{R+G+B}{3},\qquad S = 1-\frac{3\min(R,G,B)}{R+G+B}$$
:::

|          | 位图                 | 矢量图                     |
|----------|----------------------|----------------------------|
| **组成** | 像素矩阵             | 锚点 + 路径                |
| **缩放** | 放大出现色块、边缘模糊 | 缩放不失真、与分辨率无关   |
| **典型** | jpg、png、bmp        | SVG、字体、图标            |

: 位图与矢量图对比

::: {.thm title="文件大小"}
无压缩图像的数据量 $= W \times H \times \text{位深} / 8$ 字节。例如 $1920\times1080$ 的 24 位图约 6 MB。
:::

::: warn
位深 8 位的取值范围是 $0\sim255$，不是 $1\sim256$。
:::

::: intuition
把图像想成一张 Excel 表：每个格子是一个像素，格子里的数就是亮度。
:::

::: exam
先写公式，再代数，最后写单位，三步都有分。
:::

## 自测题

### 选择题

1. 归一化后某像素 $(R,G,B)=(1,1,0)$，它的 CMY 值和看到的颜色是：

   ::: choices
   - $(0,0,1)$，黄色
   - $(1,1,0)$，黄色
   - $(0,0,1)$，蓝色
   - $(0,0,1)$，青色
   :::

   ::: answer
   答：A。$C=1-R=0$，$M=1-G=0$，$Y=1-B=1$：只有黄颜料。
   :::

2. 关于 HSL 与 HSV，正确的是：

   ::: {.choices cols=1}
   - HSL 的亮度为 1 时是纯白、HSV 的明度为 1 时可以是各种饱和颜色
   - HSL 与 HSV 是同一个色彩空间的两个名字
   :::

   ::: answer
   答：A。
   :::

### 计算 BMP 大小
宽 30、高 20 的 24 位 BMP（54 字节头，每行按 4 字节对齐）：每行 $30\times3=90$ 字节，补到 92；$92\times20+54=1894$ 字节。
